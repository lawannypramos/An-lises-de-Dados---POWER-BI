# O que as empresas pedem em vagas de estágio no Brasil

Primeiro projeto prático de análise de dados, feito no Power BI, como parte da minha preparação para o primeiro estágio em TI.

## 🎯 Objetivo

Responder à pergunta: **quais habilidades as empresas brasileiras mais pedem em vagas de estágio?** — e entender se o foco está mais em habilidades técnicas ou comportamentais.

## 📊 Fonte dos dados

Estudo da **Start Carreiras**, que analisou mais de **1.400 vagas de estágio** publicadas por **757 empresas brasileiras**.

## 🛠️ Ferramentas utilizadas

- Power BI Desktop
- DAX (para a medida de destaque)
- Excel/CSV para preparação dos dados

## 📈 O que o painel mostra

1. **Ranking de habilidades** — gráfico de barras com as 10 habilidades mais citadas, ordenadas da mais para a menos pedida.
2. **Proporção técnica x comportamental** — gráfico de rosca mostrando que tipo de habilidade domina as exigências das vagas.
